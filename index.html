Reflection

Throughout this assignment, I practiced using CSS Flexbox to create a navigation bar, centered hero, and responsive card row for my Barry's Giveaways webpage while learning how to control positioning and spacing. The responsive card row was the most challenging layout for me because I had difficulty not only with the coding itself but also with figuring out the appropriate spacing between each card. I wanted the cards evenly spaced without stretching or causing display issues. I also had to revisit the gap and flex-wrap properties several times to better understand how they worked. Although reviewing material isn't a bad thing, I felt I should have understood these concepts better by this point in the semester. One example of a navigation bar I've seen outside of class is Facebook, which uses a navigation bar to help users move between different sections of the app. Another example I've seen is on a Pokémon giveaway Facebook page I'm part of, where a large title appears over a background image to introduce the page and explain what it's about. I've also noticed responsive card layouts on Indeed, where job listings are organized into individual sections that adjust depending on the screen size.
